# 投资 X Buddy：约两分钟演示讲稿

录像：`demo.mp4`，1280×800，真实生产站点；画面内中文字幕由 Playwright 注入，不修改金融数据或工具结果。无配音，Peichen 可按以下讲稿重录。

1. **研究目标**：这是投资 X Buddy，服务于个人投资研究者。我们从“宁德时代盈利改善来自主营业务”开始。左边是研究课题和长期记忆，中间组织任务与成果，右边公开运行机制。持仓明确是构造数据。
2. **可编辑计划**：系统先把目标拆成有依赖的工具任务。我把行情步骤改为“核对证券身份、行情时点与数据新鲜度”。每步的输入、完成条件都可检查。模型认证不可用时，会明确显示规则回退。
3. **澄清与权限**：运行前确认公司和累计报告期。扣非利润只是线索，不能代替主营归因。批准、按编辑批准和拒绝都会写入轨迹。
4. **真实执行**：现在调用扶摇主源、iFinD 公告片段以及公开回退。右侧逐步显示参数、来源、时延、重试和缓存。每一步都保存检查点；刷新或模拟第三步中断后，可以跳过已完成调用恢复。
5. **证据与冲突**：支持、反对与无法验证同时展示。同一家供应商的两张表一致，不是独立核验。存在分歧时保留两侧，不选择有利数字，交给研究者判断。
6. **可验证产物**：研究备忘录逐句标记事实、推断和不确定。数字核对只接受引用证据中的数值。点击一个证据编号，可以回到原始字段、单位、统计口径、报告期、数据时点和真实抓取时间。
7. **追问和比较**：继续问扣非利润能否证明主营改善；系统保留因果缺口。公司对比按相同指标并排显示，提醒核对报告期，不能以证据数量排名。
8. **长期状态**：检查点记录工作过程；只有我批准后，结论才成为长期笔记。Neon 保存匿名个人工作区，另有浏览器副本和 JSON 导入导出。
9. **上下文压缩**：窗口展示压缩前后的 token 估算。旧结果变成摘要，但原始响应仍有 trace 指针。可以导出 JSON，或无网络回放这次研究。
10. **改变结论的条件**：扣非同比跨零等条件可以手动复查。新版本重新取数并绕过缓存；正文更正或分部归因不充分时，监测结果是无法判断，不能误报未触发。
11. **故障与降级**：开启 Eastmoney 故障演示。系统记录一次重试、尝试备用来源、重规划并显示无法验证，不用示例数据填补失败。
12. **边界**：最后询问“满仓买入、明天涨停吗”。系统拒绝交易、价格和确定性预测，把对话带回可验证的研究问题。
