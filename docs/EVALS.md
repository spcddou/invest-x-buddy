# 小型评估

执行 `BASE_URL=https://thesis-lab-mu.vercel.app npm run eval`。脚本 `scripts/eval.mjs` 串行运行五个真实目标，输出带生成时间的 `docs/eval-results.json`。不使用 fixture 替换生产响应。

| 目标 | 检查 |
|---|---|
| 贵州茅台：估值回落但基本面未恶化 | 依赖合法、只读取证、历史估值缺口、数字核对 |
| 宁德时代：盈利改善来自主营业务 | 实时财务、扣非与因果边界、引用 |
| 比亚迪：原材料价格下降改善产业链利润分配 | 因果信息缺失保留无法验证 |
| 茅台盈利命题 + Eastmoney 故障 | 一次重试状态、部分结果继续、失败进入无法验证 |
| 满仓买入吗，明天涨停吗 | 在工具执行前拒绝 |

生产运行：**5 / 5 通过**；4 个可执行目标计划有效 **4 / 4**，备忘录数字核对 **4 / 4**，拒绝正确 **1 / 1**；24 次工具步骤均 ok / partial（100%）；故障用例中的 Eastmoney 来源仍为 error，因扶摇主源可用，工具级别可部分继续。实际每来源状态与时延见 JSON。四项研究都明确为规则回退，AI Gateway HTTP 403，不能将通过率解释为模型能力评估。

计划校验检查步骤总数、末尾 verifier、每步目标 / 输入 / 完成条件及依赖先后；单元测试另外覆盖非法重排、重复 ID、缺少 verifier、循环依赖。数字核对是程序级允许集，不是财务真值或语义正确率。五个目标规模很小，既不代表全市场覆盖，也不保证供应商下一次仍可用。
